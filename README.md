# WEB-Development-assessment-part-2-
ST10536537
For this assignment I made a few changes to my original Big Tech Solutions website to make it look better and easier to use. I kept most of the original information but changed the way the pages are organised and displayed. I added the same navigation bar to all the pages so that users can easily move between the Home, About Us, Services, Gallery, Contact and FAQs pages. On the Home page I added a hero section with an image and changed some of the information into cards so it is easier to read. On the About Us page I separated the information into different sections such as the history, mission, vision, target audience and the reason for having a website. On the Services page I put each service into its own card so users can see the different services more clearly. I also changed the Gallery page by adding cards with images and descriptions and made the pictures move automatically. I added Start Pictures and Stop Pictures options for the gallery. On the Contact page I added a proper contact form where users can enter their name, email, phone number, choose a service and write a message. I also changed the FAQ page so each question and answer is placed in its own card and added a button that takes the user to the Contact page.

For the CSS, I decided to use one external stylesheet called style.css because it allows me to keep the design consistent across all the pages instead of writing the same CSS on every HTML page. I chose blue and white as the main colours because I felt that blue suits a technology company and gives the website a clean and professional look. I used CSS Grid and Flexbox to organise the different parts of the website, especially the service cards, FAQ cards, contact page and navigation bar. I also added padding, margins, borders, rounded corners and box shadows to make the sections and cards look cleaner. I added hover effects to the navigation links, buttons and cards so that the website has some interaction when the user moves the mouse over them. I also added focus effects to make the buttons and form fields easier to see when they are selected. I used media queries to make the website responsive, which means the layout changes when the screen becomes smaller. For example, the cards change from multiple columns to one column on a phone and the navigation changes to fit a smaller screen. I also used responsive image settings so the images can fit different screen sizes. Overall, I mainly changed the design and layout of my original code while keeping the original information and purpose of the Big Tech Solutions website.
